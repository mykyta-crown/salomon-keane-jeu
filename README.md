# Salomon Keane

Roguelite d’action vu de dessus : un apprenti magicien gravit la tour de Morvelle la Tisseuse.

**Jouer : https://mykyta-crown.github.io/salomon-keane-jeu/**

Sur téléphone, le jeu s’installe sur l’écran d’accueil (iPhone : Safari → Partager → « Sur l’écran d’accueil » ;
Android : Chrome → « Installer ») et se relance ensuite sans réseau.

Ce dépôt ne contient que le jeu prêt à jouer, publié automatiquement depuis le dépôt de travail.
Modèles 3D : KayKit (Kay Lousberg, CC0). Musique : Kevin MacLeod (incompetech.com), CC BY 4.0.
